# Publishing Checklist

- [ ] Review all screenshots at full resolution for personal names, hostnames, IP addresses, or credentials you do not want public.
- [ ] Confirm every screenshot is from your own school lab; `(instructor example excluded)` is an instructional example and may be removed before publishing.
- [ ] Avoid uploading the instructor's original scenario or worksheet, which may contain other students' names and classroom credentials.
- [ ] Verify the screenshot gallery links display correctly on GitHub.
- [ ] Confirm the README does not claim tests that were not captured.
- [ ] Create a **public** repository named `Windows-Server-AD-File-Server-Lab`.
- [ ] Upload the **contents of this folder** (not the outer ZIP) using GitHub's Add file → Upload files; preserve directory structure.
- [ ] Add repository topics: `active-directory`, `windows-server`, `hyper-v`, `dns`, `file-server`, `it-portfolio`.
- [ ] Pin the repository to your GitHub profile.

**GitHub browser tip:** Extract the ZIP on your computer, open the extracted folder, select all its contents, then drag them into the GitHub upload page. Review the file list before committing.
